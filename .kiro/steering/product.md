# Product Overview

## Marine Engineering Project Management System

A comprehensive web application for managing marine engineering projects, quotations, materials, invoices, and customer relationships.

## Core Features

- **Quotation Management** - Create and manage price quotations with line items and scope of work
- **Project Tracking** - Monitor project progress, timelines, and assignments
- **Customer Management** - Maintain customer database with contact information
- **Materials Catalog** - Track materials, pricing, suppliers, and inventory
- **Material Requests** - Request materials for projects with approval workflows
- **Expense Tracking** - Record and monitor project costs and operational expenses
- **Invoice Management** - Generate invoices with payment tracking
- **Project Reporting** - Create completion reports with signatures and file uploads
- **Dashboard Analytics** - View project statistics and financial summaries

## User Roles

- **Leader** - Full system access, user management, financial oversight
- **Sales** - Quotations, customers, project creation
- **Accounting** - Invoices, financial data, expense approval
- **Engineer** - Project assignments, material requests, cost tracking

## Two Implementations

1. **nas/** - Next.js 14+ App Router implementation (primary, modern)
2. **apps/web/** - React Router 7 + Hono implementation (alternative)

Both share similar features but use different tech stacks and architectures.
